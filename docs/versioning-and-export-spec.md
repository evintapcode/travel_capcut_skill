# Versioning and Export Spec

## 1. Standard export versions
Prepare these variants when needed:
- 30s vertical
- 45s vertical
- 60s vertical
- 90s vertical
- 2 min vertical
- 3 min vertical

## 2. Platform-specific adaptions
- TikTok / Reels: punchy hook, strong first 3s, short CTA
- Facebook ads: stronger CTA and messaging clarity
- Instagram story style: shorter scenes, simpler pacing
- YouTube Shorts: faster cuts and stronger opening image
- Landing page: richer storytelling, more context, slower pacing

## 3. Output specs
- Resolution: 1080x1920
- Frame rate: 30fps
- Codec: H.264
- File type: MP4
- Audio: normalized, consistent volume
- Subtitles: on by default for Russian language

## 4. Version naming convention
Use naming like:
- luxury-vietnam-30s-rus-v1.mp4
- luxury-vietnam-60s-rus-v1.mp4
- luxury-vietnam-90s-rus-v1.mp4

## 5. Delivery checklist
- correct aspect ratio
- correct duration
- correct subtitles
- correct CTA frame
- brand colors consistent
- music licensing reviewed
- file quality checked
- final preview passed

## 6. QA pass rule
Every export should pass:
- brand check
- message check
- pacing check
- subtitle check
- audio check
- CTA check
- platform check
- final render check
